# 11 · 新手部署（照着点就行）

> 这篇是给**完全没用过 Cloudflare Workers** 的人写的。
> 全程在浏览器里点，**不需要在自己电脑上安装任何东西**（Git、Node、wrangler 都不用装）。
>
> 想了解「为什么这么设计」→ [05-部署上线](./05-部署上线.md)；
> 想看所有配置项 → [09-系统操作手册](./09-系统操作手册.md)；
> 出问题先翻 [07-踩坑记录](./07-踩坑记录.md)。

**做完你会得到**：一个属于你自己的代理节点、一条订阅链接、一个能在线改配置的管理面板。

---

## 你需要准备的东西（约 10 分钟）

| 准备 | 说明 | 没有怎么办 |
|---|---|---|
| Cloudflare 账号 | 免费版就够 | 去 cloudflare.com 注册 |
| 一个域名 | 必须已经接入 Cloudflare（NS 指向 CF） | 任意域名都可以，便宜的就行 |
| GitHub 账号 | 用来跑自动部署 | 去 github.com 注册 |

> 全程**免费**：Workers 免费版、D1 免费版、GitHub Actions 免费额度都够用。

---

## 第 1 步 · Fork 仓库

打开本仓库 → 右上角 **Fork** → 直接点 **Create fork**。

之后你自己的仓库地址是：`https://github.com/<你的用户名>/any-proxy`
**后面所有操作都在你 fork 出来的这个仓库里做**，别跑回原仓库。

---

## 第 2 步 · 从 Cloudflare 拿 4 个值

登录 Cloudflare 控制台，依次拿：

| 要拿什么 | 在哪里点 | 长什么样 |
|---|---|---|
| **Account ID** | 首页右侧栏「Account ID」（或 Workers & Pages 页面右侧） | 一串 32 位十六进制 |
| **Zone ID** | 点进你的域名 → 概览 → 右下角「Zone ID」 | 同上 |
| **API Token** | 右上角头像 → 我的个人资料 → API 令牌 → 创建令牌 → 选模板 **「编辑 Cloudflare Workers」** | `xxxx…`（只显示一次，先复制到记事本） |
| **D1 database_id** | 左侧 Workers & Pages → D1 → 创建数据库，名字填 `any-proxy-db` → 建好后点进去，复制 **database_id** | UUID 形态 |

> **API Token 一定要包含 DNS 的编辑权限**（模板自带的权限不够时，手动加一条 `Zone - DNS - Edit`）。
> 没有它，「自动优选 IP」会明确报错说缺凭据 —— 那正是你后面会觉得"节点不快"的原因。

---

## 第 3 步 · 把 ID 填进 wrangler.toml（**最容易漏的一步**）

在你 fork 的仓库里，打开 `wrangler.toml`，把这两个 ID 换成**你自己刚才复制的**：

```toml
[[d1_databases]]
database_id = "2d033029-8ed0-4d2b-8291-b261d21bb5d6"   # ← 换成你的 D1 database_id

[[kv_namespaces]]
id = "2a940bcb0dae4b448e8def3ebf4fe27d"                # ← 只有用 kv 后端才需要改（默认是 d1）
```

**为什么必须改**：这两个 ID 是存储资源的门牌号，仓库里写的是作者账号下的。不改的话部署会直接失败（提示找不到资源）。
默认走 D1，所以**只改 `database_id` 一行就够**。

改完点 **Commit changes**。

---

## 第 4 步 · 在 GitHub 里填 Secrets（密码类）

你的仓库 → **Settings** → 左侧 **Secrets and variables** → **Actions** → **New repository secret**，逐个填：

| Secret 名 | 填什么 | 不填会怎样 |
|---|---|---|
| `PASSWORD` | 你自己想的管理口令（**记下来，进面板要用**） | 面板进不去 |
| `CLOUDFLARE_API_TOKEN` | 第 2 步的 API Token | 部署失败 |
| `CLOUDFLARE_ACCOUNT_ID` | 第 2 步的 Account ID | 部署失败 |
| `CF_ZONE_ID` | 第 2 步的 Zone ID | 能部署，但自动优选会报错 |

再切到 **Variables** 标签页，加这两个（非敏感，填了更省心）：

| Variable 名 | 填什么 | 作用 |
|---|---|---|
| `PROXY_HOST` | 你想用来当节点的域名，如 `proxy.你的域名.com` | 自动优选往这个域名的 A 记录上写 IP。**定时任务必须靠它**，留空则只在有人访问时才推导得出 |
| `DISGUISE_PATH` | 一个你自己知道的隐蔽路径，如 `/mypanel` | 首页伪装时用它进面板（也可以放 Secret 里更安全） |

---

## 第 5 步 · 让它自己部署

仓库页 → 顶部 **Actions** → 左侧 **Deploy to Cloudflare Workers** → 右侧 **Run workflow** → 绿色的 **Run workflow**。

等 2~3 分钟，变成**绿色 ✅** 就成了。（第一次可能提示要先启用 Actions，点同意即可。）

**怎么看到我的网址**：点进那次运行 → 点 **Deploy Worker** 这一步 → 日志里有类似
`https://any-proxy.<一串字符>.workers.dev` 的地址，这就是你的站点。

想用自己的域名：Cloudflare 控制台 → Workers & Pages → 你的 any-proxy → 设置 → 触发器 → 添加自定义域名。

---

## 第 6 步 · 进管理面板

浏览器打开下面任意一个：

| 地址 | 什么时候用 |
|---|---|
| `https://你的域名/__admin` | 没开伪装时 |
| `https://你的域名/<你设的 DISGUISE_PATH>` | 开了伪装时（首页会显示"站点维护中"，这是**正常的**） |

口令就是第 4 步填的 `PASSWORD`。

---

## 第 7 步 · 必做的三件事（决定快不快）

1. **填订阅链接**：面板 → `代理节点` 页 → 订阅链接 → 保存。
2. **点一次「浏览器自动优选」**：面板 → `优选 IP` 页 → 点那个按钮，等 5~15 秒。
   它会从**你自己的网络**实测每个节点，把最快的写进池子并记下延迟。
   ⚠️ **测速时不要开着代理访问面板** —— 否则测到的是"出口节点→CF"，不是"你→CF"，结果没意义（页面会提示你）。
3. **点「立即更新优选 IP」**：把选出来的 IP 写进域名的 A 记录。

之后定时任务每 12 小时自动跑一次，不用管。

**拿订阅链接**：面板 → `代理节点` 页里复制，粘到客户端（v2rayN / Clash / sing-box）即可。

---

## 第 8 步 · 验收（看到什么算成功）

在自己电脑上打开终端（Windows 用 PowerShell），把域名换成你的，逐条跑：

```bash
# 1) 首页：开了伪装是「站点维护中」，没开是站点列表
curl -s https://你的域名/ | head -3

# 2) 页面里不能有任何面板痕迹（期望输出 0）
curl -s https://你的域名/ | grep -c "__api\|__admin"

# 3) 敏感路径必须是 404（不是 302）
curl -s -o /dev/null -w "%{http_code}\n" https://你的域名/__api/settings
```

| 检查 | 期望 |
|---|---|
| 第 1 条 | 能打开（不是报错） |
| 第 2 条 | `0` |
| 第 3 条 | `404` |

## 出问题先看这张表

| 现象 | 原因 | 怎么修 |
|---|---|---|
| Actions 红，日志说找不到 D1 / KV | 第 3 步的 ID 没改成自己的 | 改 `wrangler.toml` 里的 `database_id` |
| Actions 红，说认证失败 | API Token 不对或权限不够 | 重新生成 Token，确认带 Workers + DNS 编辑 |
| 部署成功但优选报错「缺少 CF API 凭据」 | 没填 `CF_ZONE_ID`，或 Token 没有 DNS 权限 | 补 Secret / 加权限 |
| 首页显示"站点维护中"，以为坏了 | 这是**伪装**，故意的 | 用你的隐蔽路径或 `/__admin` 进门 |
| 忘了隐蔽路径 | 在 Actions 日志或 Secret 里 | Settings → Secrets 里看 `DISGUISE_PATH` |
| 节点连不上 / 很慢 | 没做第 7 步 | 点「浏览器自动优选」→「立即更新优选 IP」 |
| 优选结果一直没变化 | 浏览器测速结果过期了（默认 12 小时） | 重新点一次「浏览器自动优选」 |
