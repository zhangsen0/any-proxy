# 10 · 用户使用指南

> 这份指南面向**最终使用者**：你拿到的是一个「代理订阅服务 + 站点反代面板」。
> 你不需要懂代码，照着下面几节就能拿到订阅、填进客户端、正常上网。
> 管理员怎么部署 / 怎么在面板里改配置，去看 `09-系统操作手册`；本文只讲「怎么用」。

---

## 1. 你能拿到什么

| 能力 | 给谁的 | 入口 |
|---|---|---|
| 主订阅链接 | 你自己 | 面板「订阅」/ 根路径 `/sub?token=…` |
| 临时订阅链接 | 借给朋友、短期分享 | 面板「临时链接」页，格式 `/tsub/<id>` |
| 站点临时访问链接 | 分享某个具体站点 | 面板「站点」里生成的 `/s/<token>/…` |
| 节点国家标注 | 自己看节点属于哪国 | 订阅节点备注自动带国家 |

核心原则：**订阅链接就是一切**。客户端只认订阅链接，不认面板。下面讲怎么拿、怎么用。

---

## 2. 拿到你的主订阅链接

订阅链接长这样：

```
https://<你的域名>/sub?token=<一串字符>
```

`token` 由「域名 + 你的 UUID」自动算出来，**不需要你手动记**。两种拿法：

1. **从面板拿（最省事）**：登录管理页 → 「订阅」或对应选项卡里会直接给出完整链接，复制即可。
2. **自己拼**：知道域名和 UUID 时，`token = MD5(MD5(域名小写 + UUID))` 的前 20 位（与 edgetunnel 口径一致）。

> 没有配置订阅链接 / UUID 时，面板会提示「无法推导 /sub token」，此时让管理员在面板里填好 `SUB_URL` 或 UUID 即可。

把链接粘贴进客户端（见第 3 节）就会拉到所有节点。

---

## 3. 把订阅填进常见客户端

所有客户端逻辑都一样：**添加「订阅」→ 粘贴上面的链接 → 更新**。

| 客户端 | 位置 | 注意 |
|---|---|---|
| v2rayN（Win）| 订阅 → 添加订阅 → 备注随便写，地址贴链接 | 贴完点「更新订阅」 |
| Clash / Clash Verge（全平台）| 订阅 → New / 导入 → 填 URL | 更新后选个好用的节点 |
| Shadowrocket（iOS）| 首页 + → 类型选「订阅」→ 贴 URL | 保存后点「更新」 |
| Sing-box / 小火箭类 | 同样是「订阅 / Subscription」入口 | 同上 |
| 浏览器插件（如 SwitchyOmega 走本地核心）| 配合 v2rayN/clash 的本地端口 | 不直接吃订阅链接 |

> 如果拉取后节点为空：先确认链接能直接在浏览器打开（应返回一串节点文本，不是登录页）；若跳登录页说明 token 算错或 UUID 没配。

---

## 4. 临时订阅链接（借给别人 / 短期用）

主订阅里是你的「长期身份」，借人怕被滥用时就用**临时订阅**：

1. 管理页 → 「临时链接」选项卡。
2. 填名称、有效天数（如 1/3/7 天）、可访问次数（0 = 不限）。
3. 生成后拿到 `/tsub/<id>`，把它当普通订阅链接发给对方即可。
4. 过期或达到次数上限后自动失效，**不影响你的主订阅**。

特点：每条临时链接有**独立随机 UUID**，和主订阅完全隔离；对方拿到的节点和你一致，但身份信息是单独的。

---

## 5. 站点临时访问链接

如果你想把「某个具体站点」短期分享给别人（而不是整个代理），用站点临时链接：

- 在「站点」选项卡里对某个站点点「生成分享链接」。
- 得到形如 `/s/<token>/<原路径>` 的链接，带有效期和访问次数上限。
- 对方打开就能直接访问那个站点，不需要任何客户端、不需要登录。

和长期入口 `/p/<id>/…` 的区别：`/p/` 是站点自己的常驻入口；`/s/` 是**另有有效期 + 次数上限**的旁路，到期即废。

---

## 6. 节点国家标注

订阅里的每个节点备注会自动带上**所属国家/地区**（如 `🇺🇸 US`、`🇯🇵 JP`），方便按地区挑节点。
开关在管理页「代理」选项卡的「节点标注」里：

- 关闭：节点备注保持原样，不产生任何额外请求。
- 开启：拉订阅时实时给每个节点补国家，样式可选（国旗 / 文字 / 隐藏）。

> 标注依赖 GeoIP 查询，首次开启可能多等一两秒，属正常。

---

## 7. 常见问题

**Q：订阅链接在浏览器打开是登录页 / 404？**
A：多半是 token 算错或 UUID 没配对（伪装开启时陌生人看到 404 是正常现象，登录后才有数据）。让管理员确认 `SUB_URL` / UUID 已配置，且你用的是登录后复制的链接。

**Q：客户端更新订阅没节点？**
A：先浏览器直接打开链接，确认返回的是节点文本而非错误页；再确认客户端「更新」按钮点了。仍为空就检查 token 与域名大小写。

**Q：临时链接过期了还能用吗？**
A：不能，过期即废，重新生成一条即可。

**Q：朋友用我的临时链接会看到我的站点/配置吗？**
A：不会。临时订阅只有节点，没有面板权限；站点临时链接只暴露那一个站点。

**Q：节点备注没国家？**
A：去「代理 → 节点标注」打开开关并保存，重新拉一次订阅。
