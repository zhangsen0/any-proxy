# 10 · 用户使用指南

> 这份指南面向**最终使用者**：你拿到的是一个「代理订阅服务 + 站点反代面板」。
> 你不需要懂代码，照着下面几节就能拿到订阅、填进客户端、正常上网。
> 管理员怎么部署 / 怎么在面板里改配置，去看 `09-系统操作手册`；本文只讲「怎么用」。

---

## 1. 你能拿到什么

| 能力 | 给谁的 | 入口 |
|---|---|---|
| 主订阅链接 | 管理员自用（需登录态） | 根路径 `/sub?token=…` |
| 临时订阅链接 | **粘进客户端就靠它**、也可借给朋友 | 面板「代理节点 → 临时订阅管理」，格式 `/tsub/<id>` |
| 站点临时访问链接 | 分享某个具体站点 | 面板「站点」里生成的 `/s/<token>/…` |
| 节点国家标注 | 自己看节点属于哪国 | 订阅节点备注自动带国家 |

核心原则：**客户端只认能匿名拉取的订阅链接**。下面先说清楚两种订阅链接的区别，这一步弄错就会「链接打不开 / 客户端没节点」。

---

## 2. 两种订阅链接：先搞清楚该用哪条

### 2.1 主订阅 `/sub?token=…` —— 需要登录态，**粘不进客户端**

```
https://<你的域名>/sub?token=<一串字符>
```

`token` 由「域名 + 你的 UUID」推导（与 edgetunnel 同一口径），**不需要你手算**。

⚠️ **开启「首页伪装」后，`/sub` 对未登录请求一律返回伪装 404**，这是刻意设计：
`/sub` 不在「始终保持匿名可达」的名单里（那份名单只有 `/__api/login`、`/__api/logout`、
`/p/<id>/…`、`/tsub/<id>` 和 WebSocket）。所以它只适合**浏览器已登录时**打开、
以及面板里的「浏览器优选」使用；**直接粘进 v2rayN / Clash 会拿到 404**。

### 2.2 临时订阅 `/tsub/<id>` —— 匿名可达，**这才是给客户端的**

1. 管理页 →「代理节点」→「临时订阅管理」→ 填名称与有效天数 → 生成；
2. 得到 `https://<你的域名>/tsub/<id>`；
3. 把这条链接粘进客户端（见第 3 节），**不需要登录即可拉取**。

它本来就是为「客户端不带 cookie」设计的，所以伪装开着也照常工作。
自己长期用就生成一条**有效期很长**的临时订阅；借给别人就生成短期的，到期即废、随时可删。

> 面板「代理节点 → 订阅链接」（`SUB_URL`）支持填完整 URL，也支持 `/tsub/xxx` 这类路径，
> 留空则回退本机 `/sub`（仅供面板自己的浏览器优选使用）。

## 3. 把订阅填进常见客户端

所有客户端逻辑都一样：**添加「订阅」→ 粘贴 `/tsub/<id>` 链接 → 更新**。

| 客户端 | 位置 | 注意 |
|---|---|---|
| v2rayN（Win）| 订阅 → 添加订阅 → 备注随便写，地址贴链接 | 贴完点「更新订阅」 |
| Clash / Clash Verge（全平台）| 订阅 → New / 导入 → 填 URL | 更新后选个好用的节点 |
| Shadowrocket（iOS）| 首页 + → 类型选「订阅」→ 贴 URL | 保存后点「更新」 |
| Sing-box / 小火箭类 | 同样是「订阅 / Subscription」入口 | 同上 |
| 浏览器插件（如 SwitchyOmega 走本地核心）| 配合 v2rayN/clash 的本地端口 | 不直接吃订阅链接 |

> 拉取后节点为空，按这个顺序排查：
> 1. 粘的是不是 `/tsub/<id>`？粘成 `/sub?token=…` 的话，伪装开启时客户端会拿到 404（见 2.1）。
> 2. 用无痕窗口（不带任何 cookie）打开该链接，应返回一串节点文本 / base64，而不是「站点维护中」。
> 3. 临时订阅是否已过期 / 被手动置为失效。

---

## 4. 临时订阅链接（给客户端用 / 借给别人）

临时订阅就是**给客户端用的那条链接**；借人怕被滥用时也用它：

1. 管理页 →「代理节点」→「临时订阅管理」。
2. 填名称、有效天数（如 1/3/7 天）。
3. 生成后拿到 `/tsub/<id>`，粘进客户端或直接发给对方。
4. 到期自动失效，也可手动置为失效或删除。

特点：每条临时链接有**独立随机 UUID**，和主订阅完全隔离；对方拿到的节点和你一致，但身份信息是单独的。
而且**匿名可达**（不需要登录），伪装开启时也照常拉取 —— 这正是它能当客户端订阅的原因。

---

## 5. 站点临时访问链接

如果你想把「某个具体站点」短期分享给别人（而不是整个代理），用站点临时链接：

- 在「站点」选项卡里对某个站点点「生成分享链接」。
- 得到形如 `/s/<token>/<原路径>` 的链接，带有效期和访问次数上限。
- 对方打开就能直接访问那个站点，不需要任何客户端、不需要登录。

和长期入口 `/p/<id>/…` 的区别：`/p/` 是站点自己的常驻入口；`/s/` 是**另有有效期 + 次数上限**的旁路，到期即废。

## 6. 节点国家标注

订阅里的每个节点备注会自动带上**所属国家/地区**（默认样式：`美国【US】`、`日本【JP】`），方便按地区挑节点。
开关在管理页「代理节点」选项卡的「节点标注」里：

- 关闭：节点备注保持原样，不产生任何额外请求。
- 开启：拉订阅时实时给每个节点补国家，样式可选：
  `中文名 + 代号`（默认，`美国【US】`）/ `国旗 + 中文名`（`🇺🇸美国`）/ `只要中文名`（`美国`）等。

> 标注依赖 GeoIP 查询，首次开启可能多等一两秒，属正常；查不到国家的节点保持原样，不会影响订阅本身。

## 7. 数据驾驶舱（看全站访问情况）

管理页左侧第一个功能区「**数据驾驶舱**」选项卡，把访问统计画成图，不用再看 JSON。

**开箱第一步：打开统计。** 默认是关闭的（关着时不记录任何数据，驾驶舱会显示一条提示）。
在驾驶舱下半屏的「统计设置」里打开「启用统计」并保存即可。

打开后能看到：

| 区块 | 内容 |
|---|---|
| KPI 一行 | 总请求数、总流量、独立访客、错误数与错误率、有数据的天数、峰值日 |
| 每日趋势 | 每天一根柱子，可切「请求数 / 流量 / 错误数」；鼠标停在柱子上看当天明细 |
| 通道排行 | 谁在用：`站点 · 名称`、代理节点、主/临时订阅、管理面板…按请求数排序，带占比条 |

右上角可切「近 7 / 14 / 30 天」并刷新；数据保留多少天由「统计设置 → 数据保留」决定，也是能回看的最长跨度。

几个说明：

- **只记哈希，不记 IP**：来访者以「IP + 安装级盐值」的哈希统计，原始 IP 不入库，服务端也反查不出来。
- **不影响速度**：计数在内存里聚合、每 15 秒批量落盘一次，不逐请求写存储。
- **看的是访客，不是自己**：管理面板自身的访问默认**不计入**（需要时可在设置里打开）。
- 「清空统计数据」只删记录，不关统计、不动其他配置。

## 8. 常见问题

**Q：订阅链接在浏览器打开是「站点维护中」/ 404？**
A：你打开的应该是主订阅 `/sub?token=…`。开启「首页伪装」后，`/sub` 对未登录请求一律返回伪装 404，这是**刻意设计**（`/sub` 不在匿名可达名单里）。要粘进客户端请改用 `/tsub/<id>`（见 2.2）。

**Q：客户端更新订阅没节点？**
A：先确认粘的是 `/tsub/<id>`（不是 `/sub?token=…`）；再用无痕窗口打开该链接，应返回节点文本 / base64 而不是「站点维护中」。仍为空就检查临时订阅是否已过期或被置为失效。

**Q：临时链接过期了还能用吗？**
A：不能，过期即废，重新生成一条即可。

**Q：朋友用我的临时链接会看到我的站点/配置吗？**
A：不会。临时订阅只有节点，没有面板权限；站点临时链接只暴露那一个站点。

**Q：节点备注没国家？**
A：去「代理 → 节点标注」打开开关并保存，重新拉一次订阅。
